Deploy a static website using GitHub Pages and make it accessible through a public URL.

## Features
- Responsive landing page
- Navigation menu
- Hero section with image
- Dark mode toggle
- Mobile-friendly design
- Deployed using GitHub Pages

## Deployment Process
1. Created a GitHub repository for the project.
2. Uploaded all website files to the repository.
3. Enabled GitHub Pages from repository settings.
4. Selected the main branch as the deployment source.
5. GitHub generated a public URL for the website.
6. Verified successful deployment by accessing the live site.
